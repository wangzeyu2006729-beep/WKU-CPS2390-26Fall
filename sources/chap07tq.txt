Multiple Choice.
---------------

1. The following is not a part of an assembly language instruction
   a. LABEL
   b. OPCODE
   c. OPERANDS
   d. COMMENT
   e. Number of cycles required to execute the instruction
   Answer: e

2. The comment in the instruction  
   ADD R1,R2,R3 ; Add contents of R3 and R2, put result in R1 is an example of

   a. a helpful comment
   b. an irrelevant comment
   c. a harmful comment
   Answer: c

3. An instruction requires a LABEL if
   a. it is the target of a branch
   b. it is the symbolic address of a data element that is referenced
   c. neither a nor b
   d, both a and b
   Answer: d


4. A ; alone on a line is
   a. an assembly error, since there is no information present
   b. a comment that serves to make the program more readable to a human by separating two parts of the program with a blank line
   c. a continuation character that tells the assembler to combine the line above the ; with the line below to form a single assembly language instruction.
   Answer: b

5. The .stringz pseudo-op translates to a sequence of ASCII codes.  The last code in the sequence is

  a. the ASCII code for the last character in the string
  b. the ASCII code of the end of text character
  c. x00
  Answer: c

6. In order to process the instruction LD R1,A
  a. the location labeled A must appear in the program before the LD instruction
  b. the location labeled A can appear anywhere in the program
  c. the location labeled A may not appear in the program provided there is a
 pseudo-op .EXTERNAL A in the program
  d. none of the above
  e. a and c
  f. b and c
  g. all of the above
  Answer: f

7. If one module contains the pseudo-op .EXTERNAL A, and no module contains the label A, the error will be detected at

  a. assembly time
  b. link time
  c. run time
  Answer: b

8. An LC-3 instruction ADD R1,R2, #45 produces an error.  It will be caught at
  a. assembly time
  b. link time
  c. run time
  Answer: a

9. An LC-3 instruction ADD R6,R7,R8 produces an error.  It will be caught at
  a. assembly time
  b. link time
  c. run time
  Answer: a


10. In LC-3 Assembly Language, the symbol #101 represents
    a. the decimal value five
    b. the decimal value one hundred and one
    c. the hex string 000100000001
    Answer: b
