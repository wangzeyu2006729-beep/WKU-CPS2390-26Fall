TRUE-FALSE
------------
1. Sometimes it is possible to carry out only a part of instruction, in which case, the computer only carries out that part of the instruction that it can (F).

2. The actual processing of information in the computer is done in the control unit (F).

3. It is possible to have an ISA with word length of four bits. (T)

4. Most ISA's provides some small temporary storage very close to the ALU to allow the results to be temporarily stored if they will be needed to produce results in the near future (T).

5. For the LC-3 ISA, the LDR instruction requires an Execute phase (F).

6. The time taken to access registers is less than the time taken to access memory. (T).

7. It is possible to have a machine without some form of input or output device. (F)

8. All instructions require all six phases of the instruction cycle to be carried out.  That is, at least one clock cycle must be devoted to carrying out the work of each phase of each instruction (F).

9. Some instructions do not require the FETCH phase (F).

10. Normally, the value in the Program Counter remains unchanged as a result of carrying out the fetch phase of the instruction cycle (F).

11. The Decode phase is required of all instructions (T).

12. The Evaluate address phase can happen before the instruction decode phase. (F).

13. If an Instruction cycle is stopped using a HALT instruction, it cannot be reinitiated using any other instruction (T).

14. The processor can interact with I/O devices using an I/O status register and I/O data register (T).

15. The Processing unit interacts with memory using the Memory Status Register and the Memory data register. (F)

16. The function of the Instruction Register is to point to next instruction to be processed.(F)

17. If the instruction at address x4000 is being processed then it is possible that the next instruction to be processed is at address x5000. (T)
